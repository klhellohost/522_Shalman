# Система учета финансов и контроля доступа

Программа на WPF для ведения финансового учета с многоуровневой системой безопасности и аналитикой расходов.

## Назначение приложения

Программное решение предназначено для организации учета финансовых операций в компании с дифференцированным доступом для сотрудников разного уровня ответственности.

## Ключевые функции

### Модуль безопасности
- Регистрация новых сотрудников в системе
- Аутентификация с проверкой уровня доступа
- Изменение паролей с контролем сложности
- Защита от перебора паролей (активация проверочного кода после 3 ошибок)
- Криптографическое преобразование паролей (алгоритм SHA1)

### Работа с учетными записями
- Отображение перечня пользователей с возможностями фильтрации и упорядочивания
- Создание/модификация/деактивация учетных записей
- Система ролей (Администратор/Сотрудник)
- Загрузка аватаров пользователей

### Учет финансовых операций
- Фиксация денежных транзакций
- Классификация платежей по категориям и ответственным лицам
- Полный цикл операций с платежами (добавление, редактирование, удаление)

### Система категоризации
- Формирование и редактирование групп расходов
- Организация платежей по тематическим группам

### Аналитика и визуализация
- Графическое представление распределения расходов по категориям
- Многоформатные диаграммы (гистограммы, секторные и другие)
- Выгрузка информации в Excel и Word/PDF

## Пользовательский интерфейс

### Варианты оформления
- **Классическая схема** - сдержанные пастельные оттенки
- **Экспресс-тема** - насыщенные яркие цвета
- Динамическое переключение стилей во время работы приложения

### Специализированные компоненты
- Интерактивные кнопки с анимацией при наведении
- Поля ввода с подсказками
- Таблицы данных с индивидуальным дизайном
- Группы элементов со скругленными границами
- Адаптивный макет

## Структура приложения

### Основные экраны
- **Экран входа** - аутентификация в системе
- **Экран регистрации** - создание новых учетных записей
- **Панель администратора** - центр управления системой
- **Рабочее место сотрудника** - персональная область пользователя
- **Экран аналитики** - графическое представление данных
- Табличные представления (Пользователи, Категории, Платежи)
- Формы добавления/редактирования (Новый пользователь, Новая категория, Новый платеж)

### Техническая основа
- **WPF** - платформа пользовательского интерфейса
- **Entity Framework** - технология работы с базой данных
- **Windows Forms Integration** - построение диаграмм (System.Windows.Forms.DataVisualization)
- **Office Interop** - функционал экспорта в Excel/Word

## Распределение полномочий

### Стандартный сотрудник
- Просмотр списка коллег
- Сортировка и фильтрация информации
- Анализ персональной финансовой статистики

### Администратор системы
- Неограниченный доступ ко всем разделам
- Управление учетными записями сотрудников
- Контроль системы категорий расходов
- Администрирование финансовых операций
- Доступ к аналитическим отчетам и их экспорту

## Аналитика и отчетность

### Графические представления
- Визуализация расходной части по категориям
- Разнообразные типы диаграмм
- Сегментация данных по пользователям

### Экспорт информации
- **Excel** - детализированные таблицы с категоризацией расходов
- **Word/PDF** - форматированные отчетные документы
- Автоматический расчет суммарных показателей

## Развертывание и запуск

### Системные требования
- .NET Framework 4.7.2 или новее
- Пакет Microsoft Office (для функций экспорта)
- SQL Server LocalDB или Express

### Процедура запуска
1. Скачать исходный код
2. Установить необходимые пакеты NuGet
3. Настроить параметры подключения к базе данных
4. Запустить приложение
